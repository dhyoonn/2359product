# 개발의뢰서 작성

화장품·식품·건기식·공산품·의료기기 4종 개발의뢰서를 자동/수동 작성하는 기능.

## 관련 파일

- `app/(document-automation)/dev-request/page.tsx` — UI (자동/수동 입력, 폼, 내보내기)
- `app/api/dev-request/route.ts` — API 라우트 (Claude 호출, 파일 파싱)
- `lib/dev-request-fields.ts` — 제품 유형별 섹션·필드 정의, 기본값
- `lib/prompts/dev-request.ts` — 자동입력 프롬프트 및 작성 규칙
- `components/FormSection.tsx` — 공통 폼 컴포넌트 (multiselect, select 등)

## 자동입력 규칙

규칙 수정 시 `lib/prompts/dev-request.ts`의 작성 원칙 항목을 변경할 것.

| 필드 | 규칙 |
|------|------|
| 유통국가_메인 | AI 미작성. 기본값: `국내` |
| 유통국가_서브 | AI 미작성. 기본값: `모두` (전 국가 자동 선택) |
| 타겟_성별_연령 | 기획안에 정보 없으면 `전 연령, 남녀 공통` |
| 기능성_메인_원료 / 부원료 | 원료명 + 함량만 기입. 효능·설명 생략 |
| 개발_요구사항 | AI 미작성. 항상 공란 |
| 기타_사항 | AI 미작성. 항상 공란 |
| 담당자명 / 연락처 | AI 미작성. 항상 공란 |
| 샘플_수령_장소 | AI 미작성. 기본값: `서울특별시 강남구 학동로23길 18, M층` |
| 제품_컨셉 | 제조사 전달용. 한 줄 간략 표현만 (예: "위 건강 다이어트") |
| 참고_타겟1 / 참고_타겟2 | 기획안에 URL 있으면 기입, 없으면 공란 |

## 상품제안서 양식 → 개발의뢰서 섹션 매핑

회사 상품제안서 양식(`상품제안서 양식.pdf` 참고) 기준 매핑 규칙.
규칙 수정 시 `lib/prompts/dev-request.ts`의 `[기획안 섹션 → 개발의뢰서 필드 매핑 규칙]` 항목을 변경할 것.

| 상품제안서 섹션 | 개발의뢰서 필드 |
|---|---|
| 기획 의도 / 제품 한 줄 요약 | 제품_컨셉 |
| 메인 소구점(USP=Identity) 및 성분 | 필수_성분 |
| 서브 소구점 및 성분 | 요청_성분 |
| 관능 및 제형 특성 | 제형 |
| 주요 타겟 전략 | 타겟_성별_연령 |
| 타겟 제품 분석 내 경쟁 제품 URL | 참고_타겟1 / 참고_타겟2 |

## 내보내기

- 형식: HTML (브라우저에서 열어 Ctrl+P로 PDF 변환 가능)
- 파일명: `YYMMDD_개발의뢰서_브랜드명_담당자명.html`
